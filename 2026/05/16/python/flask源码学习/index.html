核心设计思想：

设计 说明
WSGI 协议 Flask 本身就是一个 WSGI 应用（__call__ 方法）
上下文栈 通过 LocalStack 隔离不同线程/协程的请求，视图函数无需传参
代理模式 LocalProxy 让 request 等表现得像全局变量，实际值来自当前线程栈顶
延迟注册 Blueprint 的所有操作存入队列，register() 时一次性执行
责任链 before_request → view → after_request → teardown 形成有序处理链
签名而非加密 Session 用 itsdangerous 签名防篡改，但不加密（客户端不可见但可读）
