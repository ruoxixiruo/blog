4. 常见问题与解决

问题 1：镜像拉取失败或极慢

现象： docker pull milvusdb/milvus:v2.4.0 超时或失败。

原因： Docker Hub 在国内访问不稳定。

解决：配置国内镜像加速

镜像拉取后检查大小：正常 Milvus v2.4.0 约 **900MB+**，如果只有几十 MB 说明拉取不完整，需重新拉取。

问题 3：etcd 容器健康检查失败

现象： docker compose ps 显示 etcd unhealthy。

日志显示 etcd 已启动成功：

原因： etcd 健康检查命令错误。使用 wget http://localhost:2379/health 不对，etcd 的健康检查应用 etcdctl endpoint health。

解决方法一：去掉 healthcheck（最简单）

解决： 只加 depends_on 不加 condition: service_healthy，依赖从”等待健康”降级为”等待容器启动”。

问题 4：容器运行一段时间后自动退出

现象： Milvus 正常运行几分钟到几十分钟后容器挂掉。

原因： 常见有 3 种情况：

4.1 内存不足（最常见）

解决：限制 Milvus 内存使用
