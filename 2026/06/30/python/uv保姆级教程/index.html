uv学习教程

发表于 2026-06-30 分类于 python

uv（/ʌv/，类似”阿武”）是用 Rust 编写的极速 Python 工具链，集包管理、项目管理、版本管理于一体，速度比 pip 快 10~100 倍。

一句话总结：一个工具替代 pip + virtualenv + poetry + pyenv + pipx。

一、为什么要用 uv？

1.1 一个工具，替代五个

以前需要 现在只需
pip 安装包 uv pip install
virtualenv 创建环境 uv 自动管理
poetry / pipenv 管理项目 uv init + uv add
pyenv 管理 Python 版本 uv python install
pipx 安装全局工具 uv tool install

1.2 速度对比

1.3 适合谁用？

  • ✅ Python 开发者（数据科学 / Web / 自动化 / 脚本）
  • ✅ 团队协作项目（统一环境，避免”在我电脑能跑”）
  • ✅ 多版本 Python 需求（同时跑 3.10、3.11、3.12）
  • ✅ CI/CD 流水线（加速构建，节省时间）

三、核心概念（必读）

3.1 虚拟环境（Virtual Environment）

问题：电脑上只有一个 Python，但项目 A 需要 Django 2.0，项目 B 需要 Django 4.0，版本冲突了怎么办？

解决：虚拟环境 — 给每个项目一个”独立的 Python 房间”，互不干扰。

::: warning 重点
uv 的厉害之处：你不需要手动创建/激活虚拟环境，uv 会自动搞定！
:::

3.2 pyproject.toml（项目配置文件）

这是 uv 项目的”说明书”，放在项目根目录，记录了：

  • 项目名称和版本
  • Python 版本要求
  • 依赖包列表
  • 开发依赖列表

3.3 uv.lock（精确版本锁定文件）

记录了每个依赖包的精确版本号，确保：

  • 团队成员拉取代码后，安装的包版本完全一致
  • 6 个月后再跑项目，安装的版本仍然一致

::: tip 最佳实践
把 pyproject.toml 和 uv.lock 一起提交到 Git！
:::

四、快速上手

uv 有两种使用模式，根据你的需求选择：

4.1 模式一：不创建项目，直接装包（快速模式）

适用场景：一次性脚本、快速测试、临时用某个包。

4.2 模式二：管理项目（推荐模式）

适用场景：正式项目、团队协作、需要长期维护的代码。

十二、命令速查表

基础命令

命令 说明
uv --version 查看 uv 版本
uv help 查看帮助
uv python list 列出可用 Python 版本

Python 版本管理

命令 说明
uv python install 3.12 安装 Python 3.12
uv python uninstall 3.10 卸载 Python 3.10
uv python pin 3.11 固定项目 Python 版本

项目管理

命令 说明
uv init myproject 创建新项目
uv add requests 添加依赖
uv add --dev pytest 添加开发依赖
uv remove requests 移除依赖
uv sync 同步依赖到环境
uv sync --all-packages 同步所有依赖（含开发）
uv sync --upgrade 升级所有依赖

裸 pip 用法（不需要项目）

命令 说明
uv pip install requests 安装包
uv pip install -r requirements.txt 从文件安装
uv pip uninstall requests 卸载包
uv pip list 列出已安装
uv pip freeze 导出为 requirements

运行脚本

命令 说明
uv run python script.py 运行脚本
uv run --with requests script.py 临时加包运行
uv run pytest 运行测试
uv run black . 格式化代码

工具管理

命令 说明
uv tool install httpie 全局安装工具
uv tool list 列出已安装工具
uv tool upgrade httpie 升级工具
uv tool uninstall httpie 卸载工具

构建和发布

命令 说明
uv build 构建包
uv publish 发布到 PyPI
