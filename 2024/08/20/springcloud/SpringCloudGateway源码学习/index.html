类 职责
GatewayAutoConfiguration 自动配置入口，注册所有 Bean
RouteDefinition 路由配置模型（id + predicates + filters + uri）
Route 运行时路由对象（Predicate + Filter 列表）
RouteDefinitionLocator 路由定义定位器接口
PropertiesRouteDefinitionLocator 从 yaml 配置读取 RouteDefinition
DiscoveryClientRouteDefinitionLocator 从注册中心自动生成路由
RouteLocator 运行时路由定位器接口
RouteDefinitionRouteLocator RouteDefinition → Route（组装 Predicate + Filter）
CachingRouteLocator 缓存路由列表
CompositeRouteLocator 组合多个 RouteLocator
RoutePredicateHandlerMapping 路由匹配（请求 → 匹配 Route → 返回 WebHandler）
FilteringWebHandler 执行过滤器链
DefaultGatewayFilterChain 过滤器链实现（递归式责任链）
GatewayFilterAdapter GlobalFilter → GatewayFilter 适配器
NettyRoutingFilter 真正发起 HTTP 请求到下游
LoadBalancerClientFilter lb:// 负载均衡
RoutePredicateFactory Predicate Factory 抽象类
GatewayFilterFactory Filter Factory 抽象类
GatewayProperties 绑定 gateway 配置的 Properties
