1，Nacos 简介

Nacos（Naming and Configuration Service）是阿里巴巴开源的服务发现与配置管理平台，致力于帮助用户构建云原生应用。

两大核心功能：

  • 服务发现（Naming）：服务的注册、发现、健康检查
  • 配置管理（Config）：动态配置、配置版本管理、快速生效

核心特性：

  • 服务发现：支持 DNS / HTTP 协议
  • 配置中心：支持配置热更新，毫秒级生效
  • 动态 DNS：支持基于权重的路由
  • 服务健康检查：TCP / HTTP / MySQL 探测
  • 多数据中心：支持同城/异地多活
  • AP / CP 模式切换：根据场景选择一致性 or 可用性

操作 API 说明
注册实例 POST /nacos/v1/ns/instance 注册服务实例
发现实例 GET /nacos/v1/ns/instance/list 查询服务实例列表
心跳 PUT /nacos/v1/ns/instance/beat 临时实例心跳
注销实例 DELETE /nacos/v1/ns/instance 注销服务实例
更新实例 PUT /nacos/v1/ns/instance 修改权重等元数据
健康开关 PUT /nacos/v1/ns/health/instance 手动上下线
服务列表 GET /nacos/v1/ns/service/list 查询全部服务
服务详情 GET /nacos/v1/ns/service 查询服务详情
获取配置 GET /nacos/v1/cs/configs 拉取配置内容
发布配置 POST /nacos/v1/cs/configs 新建/更新配置
删除配置 DELETE /nacos/v1/cs/configs 删除配置
监听配置 POST /nacos/v1/cs/configs/listener 长轮询监听变更
获取命名空间 GET /nacos/v1/console/namespaces 查询命名空间列表
