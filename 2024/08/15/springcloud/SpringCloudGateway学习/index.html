1，Gateway 简介

Spring Cloud Gateway 是 Spring 官方基于 WebFlux 开发的 API 网关，替代 Netflix Zuul。它使用非阻塞异步模型，性能优于传统 Servlet 网关。

核心概念：

  • Route（路由）：网关的基本构建块，由 ID、目标 URI、Predicates 和 Filters 组成
  • Predicate（断言）：匹配 HTTP 请求的条件，如 Path、Header、Method 等
  • Filter（过滤器）：对请求和响应进行修改，分 GatewayFilter 和 GlobalFilter
  • 当请求到达网关时，匹配到 Route 后，请求经过 Filter 链，最终转发到目标 URI
