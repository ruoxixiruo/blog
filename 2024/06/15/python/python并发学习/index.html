1，Python 并发概述

Python 有多种并发模型，选择取决于任务类型：

模型 适用场景 切换开销 GIL 影响
threading 多线程 I/O 密集型（网络、文件） 低 严重（无法利用多核 CPU）
multiprocessing 多进程 CPU 密集型（计算、图像处理） 高 无（各进程有独立 GIL）
asyncio 协程 高并发 I/O（大量网络连接） 极低 无影响（单线程）
concurrent.futures 简化线程/进程池操作 低/高 同上

GIL（全局解释器锁）：CPython 的全局锁，同一时刻只有一个线程执行 Python 字节码。I/O 操作时 GIL 会释放。

绕过 GIL 的策略：multiprocessing、C 扩展中释放 GIL、使用其他 Python 实现（Jython 无 GIL）、Python 3.13+ 可选无 GIL 模式。
