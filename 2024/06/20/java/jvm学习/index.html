1，JVM 概述

JVM（Java Virtual Machine）是 Java 程序运行的核心，负责将字节码解释/编译为机器码执行。不同平台有各自的 JVM 实现，实现了”一次编译，到处运行”。

主流 JVM 实现：

  • HotSpot：Oracle/Sun 官方 JVM，最常用（JDK 1.3+ 默认）
  • OpenJ9：IBM 开源 JVM，启动快、内存占用低
  • GraalVM：高性能多语言虚拟机，支持 AOT 编译
