1，Java 简介

Java 是由 Sun Microsystems（后被 Oracle 收购）于 1995 年发布的面向对象编程语言。James Gosling 是 Java 之父。

核心特点：

  • 跨平台：一次编译，到处运行（Write Once, Run Anywhere）—— 编译为字节码，由各平台 JVM 解释执行
  • 面向对象：封装、继承、多态
  • 自动内存管理：垃圾回收（GC），无需手动释放内存
  • 强类型：编译时类型检查，减少运行时错误
  • 丰富的生态：Spring、MyBatis、Hadoop 等

三大版本：

  • Java SE（Standard Edition）：标准版，核心基础
  • Java EE（Enterprise Edition）：企业版，Web 开发
  • Java ME（Micro Edition）：微型版，嵌入式
2，JDK 安装与配置

JDK 组成：

  • javac：编译器，将 .java 源文件编译为 .class 字节码
  • java：执行工具，启动 JVM 运行字节码
  • JVM：Java 虚拟机，真正运行程序的地方
  • JRE：运行环境 = JVM + 核心类库
  • JDK：开发工具包 = JRE + 开发工具（javac、jar、javadoc 等）
