maven仓库
  • 用于存储资源，管理各种jar包

  • 本地仓库：自己计算机上的一个目录

  • 中央仓库：由maven团队维护的全球唯一的

  • 远程仓库（私服)： 一般又公司团队搭建的私有仓库

maven安装
配置maven环境
  • 选择IDEA中File -> settings -> Build, Execution, Deployment -> build tools -> maven
  • 设置IDEA使用本地安装的maven，并修改配置文件及本地仓库路径
  • 配置Maven ,Maven/Runner, Complier/java compiler
创建maven项目
  • 进入项目目录，创建模块，选择maven，点击next
  • 填写模块名称，坐标信息，点击finish
导入maven项目
  • 打开IDEA，选择maven面板，点击+号，选中对应项目的pom.xml文件，双击即可
