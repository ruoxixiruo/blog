1，Spring Boot 简介

Spring Boot 是 Spring 家族的核心子项目，旨在简化 Spring 应用的初始搭建和开发过程。通过”约定大于配置”的理念和自动配置机制，让开发者能快速创建独立、生产级的 Spring 应用。

为什么要用 Spring Boot？

  • 快速搭建：几分钟内创建一个独立运行的 Web 应用
  • 内嵌服务器：内置 Tomcat / Jetty / Undertow，无需部署 WAR 包
  • 自动配置：根据依赖自动配置 Spring 和第三方库
  • 起步依赖（Starter）：一站式引入相关依赖，无需手动管理版本
  • 生产就绪：内置健康检查、指标监控、外部化配置
  • 无代码生成：无需 XML 配置，几乎无需代码生成

与传统 SSM 对比：

对比项 SSM（Spring+SpringMVC+MyBatis） Spring Boot
项目搭建 配置繁琐，需要大量 XML 几分钟，自动配置
依赖管理 手动解决版本冲突 Starter 起步依赖自动管理
部署 打 WAR 包，部署到 Tomcat 打 JAR 包，内嵌服务器 java -jar
配置 大量 XML / properties application.yml，外部化配置
监控 需自行集成 Actuator 开箱即用

Starter 用途
spring-boot-starter-web Web 开发（Spring MVC + Tomcat）
spring-boot-starter-webflux 响应式 Web 开发（WebFlux ）
spring-boot-starter-test 测试（JUnit 5 + Mockito）
spring-boot-starter-data-jpa JPA + Hibernate
spring-boot-starter-data-redis Redis 集成（Lettuce）
spring-boot-starter-data-mongodb MongoDB 集成
spring-boot-starter-security Spring Security
spring-boot-starter-validation Bean Validation
spring-boot-starter-aop AOP 切面
spring-boot-starter-actuator 健康监控
spring-boot-starter-mail 邮件发送
spring-boot-starter-quartz Quartz 定时调度
spring-boot-starter-websocket WebSocket
spring-boot-starter-batch 批处理
spring-boot-devtools 热部署（开发用）
spring-boot-configuration-processor 配置元数据（自动补全）
