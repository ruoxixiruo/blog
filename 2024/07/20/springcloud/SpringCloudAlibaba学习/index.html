1，微服务与 Spring Cloud Alibaba 概述

微服务架构 是将单一应用拆分为一组小型服务，每个服务独立部署、独立扩展，服务间通过轻量级通信机制协作。

版本对应关系（Spring Cloud Alibaba 2022.x）：

组件 版本
Spring Boot 3.0.x / 3.1.x / 3.2.x
Spring Cloud 2022.0.x
Spring Cloud Alibaba 2022.0.0.x
Nacos 2.2.x
Sentinel 1.8.6
Seata 1.7.x
RocketMQ 5.1.x

Nacos（Naming and Configuration Service）是阿里巴巴开源的服务发现与配置管理平台。

5，Sentinel —— 流量控制与熔断降级

6，Seata —— 分布式事务

Seata 提供 AT、TCC、SAGA、XA 四种分布式事务模式，AT 模式最常用（无侵入）。

场景 组件 说明
服务发现 Nacos / Consul / Eureka Nacos 首选，服务发现+配置中心二合一
配置中心 Nacos / Apollo Nacos 轻量，Apollo 功能更强
远程调用 OpenFeign / Dubbo Feign 适合 HTTP REST，Dubbo 适合高性能 RPC
负载均衡 LoadBalancer Spring Cloud 官方，替代 Ribbon
限流熔断 Sentinel / Hystrix Sentinel 功能更强，实时监控更友好
API 网关 Gateway / Zuul Gateway 基于 WebFlux，异步非阻塞
分布式事务 Seata AT 模式无侵入，TCC 模式高性能
消息队列 RocketMQ / Kafka RocketMQ 阿里系，Kafka 大数据场景
链路追踪 SkyWalking / Zipkin SkyWalking 无代码侵入，功能全
分布式锁 Redisson 基于 Redis，看门狗自动续期
分布式 ID Leaf / Snowflake 美团 Leaf 或雪花算法
配置加密 jasypt 配置文件密码加密
