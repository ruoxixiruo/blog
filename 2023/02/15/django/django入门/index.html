1，Django 简介

Django 是一个用 Python 编写的开源 Web 框架，遵循 MTV（Model-Template-View）架构模式，于 2005 年首次发布。设计哲学是”快速开发”和”DRY（Don’t Repeat Yourself）”。

核心特点：

  • 完整的全栈框架，自带 ORM、模板引擎、认证系统、管理后台
  • 完善的文档和活跃的社区
  • 高度可扩展，插件化设计
  • 强大的安全防护（XSS、CSRF、SQL 注入等默认防范）
  • 适合快速构建内容型网站和复杂 Web 应用

MTV 架构：

  • Model（模型）：数据层，定义数据结构，与数据库交互
  • Template（模板）：表现层，定义页面如何渲染
  • View（视图）：业务逻辑层，接收请求，处理数据，返回响应
