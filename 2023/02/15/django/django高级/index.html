请求处理流程（简化）：

  1. WSGIHandler 接收请求 → 封装为 HttpRequest
  2. BaseHandler.get_response() → 按顺序遍历所有中间件的 process_request
  3. URLResolver.resolve() → 匹配 URL，找到对应的视图函数
  4. 执行视图 → 视图返回 HttpResponse
  5. 按逆序遍历所有中间件的 process_response
  6. 返回 HttpResponse 给 WSGI 服务器

模型保存流程（简化）：

  1. model.save() → Model.save_base()
  2. 发送 pre_save 信号
  3. 调用 Model._do_update() 或 Model._do_insert()
  4. QuerySet._update() / QuerySet._insert() → SQL 编译器
  5. SQLCompiler.execute_sql() → 执行 SQL
  6. 发送 post_save 信号
