1，Python 简介

Python 由 Guido van Rossum 于 1991 年发布，是一门解释型、面向对象的高级编程语言。设计哲学强调代码可读性和简洁的语法。

核心特点：

  • 解释型语言，无需编译，逐行执行
  • 动态类型，变量无需声明类型
  • 自动内存管理（垃圾回收）
  • 跨平台：Windows、Linux、macOS
  • 丰富的标准库和第三方生态
  • 支持多种编程范式：面向过程、面向对象、函数式

应用领域：

  • Web 开发（Django、Flask、FastAPI）
  • 数据科学与机器学习（NumPy、Pandas、PyTorch）
  • 自动化运维与测试
  • 网络爬虫
  • 桌面应用开发

19，编码规范 (PEP 8)
  • 使用 4 个空格缩进，不要用 Tab
  • 每行不超过 79 个字符（注释/docstring 不超过72）
  • 顶层函数和类之间用两个空行隔开
  • 类内方法之间用一个空行隔开
  • 导入在文件顶部，按顺序分组：标准库 → 第三方库 → 本地模块，每组之间空一行
  • 命名约定：
    • 变量、函数、方法：snake_case
    • 类：PascalCase
    • 常量：UPPER_CASE
    • 保护属性：_leading_underscore
    • 私有属性：__double_underscore
  • 运算符两侧各留一个空格
  • 逗号、冒号后跟一个空格
  • 不要用 from module import *
  • 不要在一行写多个语句
