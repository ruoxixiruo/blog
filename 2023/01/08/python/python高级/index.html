1，元类

元类是创建类的类。type 是 Python 中所有类的默认元类。当解释器遇到 class 语句时，底层实际调用的是 type(name, bases, namespace)。

类创建的过程分为两步：

  1. __new__ — 创建类的命名空间
  2. __init__ — 初始化类对象
2，属性描述符

描述符协议规定了三个方法：__get__、__set__、__delete__。实现了其中任意一个方法的类的实例就是描述符。

数据描述符查找优先级（从高到低）：

  1. 数据描述符（有 __get__ 和 __set__）→ 覆盖实例字典
  2. 实例字典 __dict__
  3. 非数据描述符（只有 __get__）→ 实例字典优先
  4. 类属性
  5. __getattr__ 兜底

18，GIL 深入理解

GIL（Global Interpreter Lock）是 CPython 解释器的全局锁，保证同一时刻只有一个线程执行 Python 字节码。这简化了 CPython 的内存管理（引用计数不需要原子操作），但也限制了多线程的 CPU 并行能力。

绕过 GIL 的策略：

  • multiprocessing：每个进程有独立 Python 解释器，用于 CPU 密集型
  • C 扩展：在 C 代码中手动释放 GIL
  • 其他 Python 实现：Jython（JVM）、IronPython（.NET）无 GIL；PyPy 有 GIL 但 JIT 提升单线程性能；Python 3.13+ 引入可选的无 GIL 模式
