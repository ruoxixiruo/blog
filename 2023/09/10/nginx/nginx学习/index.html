1，Nginx 简介

Nginx（engine X）是一个高性能的 HTTP 和反向代理服务器，同时提供 IMAP/POP3/SMTP 代理服务。由 Igor Sysoev 于 2004 年发布。

核心特点：

  • 高并发：基于事件驱动的异步非阻塞架构，单机可支撑数万并发连接
  • 低内存：每个连接仅占用极少内存
  • 热部署：支持不中断服务地升级和重载配置
  • 功能丰富：反向代理、负载均衡、静态文件服务、SSL 终结、HTTP 缓存

应用场景：

  • 静态资源服务器
  • 反向代理 + 负载均衡
  • SSL/TLS 终结
  • WebSocket 代理
  • HTTP 缓存加速
  • 流媒体服务

15，TCP/UDP 代理（Stream 模块）

Nginx 的 stream 模块提供四层（TCP/UDP）代理能力，工作在传输层，不解包 HTTP 协议。适用于代理 MySQL、Redis、SSH 等 TCP 协议，或 DNS 等 UDP 协议。

19，命令速查表
命令 说明
nginx -t 检查配置文件语法
nginx -T 检查语法并输出完整配置
nginx -s reload 热重载配置
nginx -s stop 快速停止
nginx -s quit 优雅停止
nginx -s reopen 重开日志文件
nginx -V 查看版本与编译参数
sudo systemctl start nginx 启动
sudo systemctl stop nginx 停止
sudo systemctl reload nginx 重载
sudo systemctl restart nginx 重启
tail -f /var/log/nginx/access.log 查看访问日志
tail -f /var/log/nginx/error.log 查看错误日志
