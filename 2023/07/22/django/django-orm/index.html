参数 类型 说明
null=True bool 数据库层面允许 NULL
blank=True bool 表单验证允许为空
default=value any 默认值，可以是值或可调用对象
unique=True bool 唯一约束
unique_for_date="pub_date" str 日期维度唯一
db_index=True bool 创建数据库索引
db_column="col_name" str 自定义数据库列名
primary_key=True bool 设为主键（会替换 id）
editable=False bool Admin 和 ModelForm 中不可编辑
verbose_name="名称" str 可读名称
help_text="提示" str 帮助文本，Admin 中显示
choices=[(val, label), ...] list 可选项列表
validators=[...] list 自定义验证器列表
error_messages={...} dict 自定义错误消息
max_length=200 int 最大长度（CharField 必填）

12，F 查询

F() 表达式允许在查询中引用模型字段的值，避免了将数据读到 Python 层面的开销。

13，Q 查询

Q() 对象用于构建复杂查询条件（OR、NOT、嵌套）。

14，select_related 与 prefetch_related

两者都是为了减少 SQL 查询次数（解决 N+1 问题），但实现方式不同。

特性 select_related prefetch_related
机制 SQL JOIN 分开查询 + Python 拼接
SQL 数量 1 条 2 条（主查询 + 预取查询）
适用关系 ForeignKey / OneToOneField ManyToManyField / ForeignKey 反向
结果类型 JOIN 后的大表 Python 内存中拼接

23，查询优化技巧清单
技巧 说明
select_related() FK/OneToOne 用 JOIN 一次查询
prefetch_related() M2M/反向查询用分批预取
values()/values_list() 不需要模型实例时只取字段
only()/defer() 只加载需要的字段
annotate() 代替循环计数 用聚合代替 N+1 查询
iterator() 流式处理大数据集
bulk_create() 批量创建，比逐条 save 快百倍
bulk_update() 批量更新，避免逐条 save
exists() 代替 if qs: 判断是否存在，性能更好
count() 代替 len(qs) 用 SQL COUNT 代替 Python len
update() 代替循环 save() 直接 SQL UPDATE
创建索引 对常过滤的字段加 db_index=True
分页避免全量加载 用 Paginator 分页
预编译正则 re.compile() 用于复杂过滤
explain() 分析查询计划
避免 order_by(“?”) 随机排序极耗性能
