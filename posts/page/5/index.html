1，Flask 上下文概述

Flask 中有两种上下文：

  • 请求上下文（Request Context）：request 和 session
  • 应用上下文（Application Context）：current_app 和 g

Flask 的设计中，请求和应用信息不是通过全局变量直接访问的，而是通过上下文机制将特定请求/应用的数据绑定到当前线程（或协程）。这使得 Flask 支持多线程，且可以运行多个 Flask 应用实例。

核心原理：Werkzeug 的 LocalProxy + LocalStack。

发表于 2023-08-01 分类于 flask
1，Flask 简介

Flask 是一个用 Python 编写的轻量级 Web 框架，基于 Werkzeug（WSGI 工具库）和 Jinja2（模板引擎）。由 Armin Ronacher 于 2010 年创建。

核心设计哲学：

  • 微框架：核心极简（请求路由、请求/响应处理、模板渲染），其他功能通过扩展实现
  • 灵活：不强制项目结构、数据库 ORM 或任何特定库
  • 易于扩展：丰富的扩展生态，按需添加功能
  • 学习曲线平缓：API 直观，文档完善

适用场景：

  • 中小型 Web 应用
  • RESTful API 服务
  • 微服务
  • 快速原型开发
  • 单页应用（SPA）后端
