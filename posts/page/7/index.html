python入门

发表于 2023-01-08 分类于 python
1，Python 简介

Python 由 Guido van Rossum 于 1991 年发布，是一门解释型、面向对象的高级编程语言。设计哲学强调代码可读性和简洁的语法。

核心特点：

  • 解释型语言，无需编译，逐行执行
  • 动态类型，变量无需声明类型
  • 自动内存管理（垃圾回收）
  • 跨平台：Windows、Linux、macOS
  • 丰富的标准库和第三方生态
  • 支持多种编程范式：面向过程、面向对象、函数式

应用领域：

  • Web 开发（Django、Flask、FastAPI）
  • 数据科学与机器学习（NumPy、Pandas、PyTorch）
  • 自动化运维与测试
  • 网络爬虫
  • 桌面应用开发
