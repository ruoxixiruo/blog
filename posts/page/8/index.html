1，Docker 基础概念
  • 镜像（Image）：应用程序及其运行环境的只读模板
  • 容器（Container）：镜像的运行时实例
  • 仓库（Registry）：存储和分发镜像的地方（Docker Hub、私有仓库）
2，镜像命令
3，容器命令

9，Dockerfile 常用指令速查
指令 说明 示例
FROM 基础镜像 FROM python:3.11-slim
RUN 构建时执行命令 RUN pip install flask
CMD 容器默认启动命令（可覆盖） CMD ["python", "app.py"]
ENTRYPOINT 容器入口点（不可被 docker run 命令覆盖） ENTRYPOINT ["python"]
COPY 复制文件到镜像 COPY . /app
ADD 复制文件（支持 URL 和自动解压 tar） ADD archive.tar.gz /app
WORKDIR 设置工作目录 WORKDIR /app
ENV 设置环境变量 ENV FLASK_APP=app.py
EXPOSE 声明暴露端口 EXPOSE 5000
VOLUME 声明卷挂载点 VOLUME /data
USER 切换用户 USER appuser
ARG 构建参数 ARG NODE_VERSION=18
LABEL 元数据标签 LABEL version="1.0"
HEALTHCHECK 健康检查 HEALTHCHECK CMD curl -f http://localhost/
SHELL 指定默认 shell SHELL ["/bin/bash", "-c"]
10，docker run 参数速查表
参数 说明
-d 后台运行
-i 交互模式（保持 STDIN 打开）
-t 分配伪 TTY
--name 容器名称
-p HOST:CONTAINER 端口映射
-P 随机端口映射
-v HOST:CONTAINER 绑定挂载
-v VOLUME:CONTAINER 命名卷挂载
-e KEY=VALUE 环境变量
--env-file 从文件加载环境变量
--rm 退出时自动删除
--restart 重启策略
--network 网络模式
--memory / --cpus 资源限制
-w 工作目录
-h 主机名
--privileged 特权模式
--user 用户
--dns DNS 服务器
--add-host 添加 hosts 记录
