redis学习

发表于 2026-05-16 分类于 redis
1，Redis 简介

Redis（Remote Dictionary Server）是一个开源的、基于内存的键值存储系统，由 Salvatore Sanfilippo 于 2009 年发布。它常被用作数据库、缓存、消息代理和流处理引擎。

核心特点：

  • 基于内存：所有数据存放在内存中，读写速度极快（读 11 万/s，写 8 万/s）
  • 单线程模型：使用单线程处理命令，避免上下文切换和锁竞争（6.0 后引入多线程 I/O，但命令执行仍是单线程）
  • 持久化支持：支持 RDB 快照和 AOF 日志两种持久化方式
  • 丰富的数据类型：String、Hash、List、Set、Sorted Set、Bitmap、HyperLogLog、Geo、Stream
  • 高可用：支持主从复制、哨兵模式、集群模式
  • 原子操作：所有命令都是原子性的
  • 过期策略：支持为 key 设置过期时间，到期自动删除

与 Memcached 的对比：

特性 Redis Memcached
数据结构 丰富（String/List/Set 等） 仅 String
持久化 支持 RDB + AOF 不支持
集群 原生 Cluster + Sentinel 客户端分片
线程模型 单线程 + IO 多线程 多线程
内存管理 jemalloc slab allocation
事务 支持（非严格 ACID） 不支持

应用场景：

  • 缓存（热点数据、页面缓存、Session 共享）
  • 排行榜/计数器（Sorted Set 实现实时排行）
  • 分布式锁（SETNX + 过期时间）
  • 消息队列（List 阻塞队列 + Stream）
  • 社交关系（Set 实现关注/粉丝/共同好友）
  • 地理位置（Geo 实现附近的人）
  • 限流（滑动窗口 + 令牌桶）
  • 布隆过滤器（Bitmap + Hash 函数）

发表于 2024-08-15 分类于 java
1，Gateway 简介

Spring Cloud Gateway 是 Spring 官方基于 WebFlux 开发的 API 网关，替代 Netflix Zuul。它使用非阻塞异步模型，性能优于传统 Servlet 网关。

核心概念：

  • Route（路由）：网关的基本构建块，由 ID、目标 URI、Predicates 和 Filters 组成
  • Predicate（断言）：匹配 HTTP 请求的条件，如 Path、Header、Method 等
  • Filter（过滤器）：对请求和响应进行修改，分 GatewayFilter 和 GlobalFilter
  • 当请求到达网关时，匹配到 Route 后，请求经过 Filter 链，最终转发到目标 URI

1，Feign 简介

Feign 是 Netflix 开源的声明式 HTTP 客户端，通过接口 + 注解的方式简化 HTTP 远程调用。Spring Cloud OpenFeign 在其基础上整合了 Spring MVC 注解、Spring Cloud LoadBalancer、Sentinel 等组件。

核心理念：定义接口即可完成远程调用，无需手动拼接 URL、构建请求。

与 RestTemplate 对比：

对比项 RestTemplate Feign
调用方式 手动拼接 URL，代码冗长 接口+注解，声明式
可读性 一般 高，符合面向接口编程
负载均衡 需 @LoadBalanced 自动集成 Ribbon/LoadBalancer
熔断降级 需手动集成 一行配置集成 Sentinel/Hystrix
编码器 需手动处理 JSON 自动集成 Encoder/Decoder
拦截器 需手动添加 RequestInterceptor 统一处理

nacos学习

发表于 2024-08-01 分类于 java
1，Nacos 简介

Nacos（Naming and Configuration Service）是阿里巴巴开源的服务发现与配置管理平台，致力于帮助用户构建云原生应用。

两大核心功能：

  • 服务发现（Naming）：服务的注册、发现、健康检查
  • 配置管理（Config）：动态配置、配置版本管理、快速生效

核心特性：

  • 服务发现：支持 DNS / HTTP 协议
  • 配置中心：支持配置热更新，毫秒级生效
  • 动态 DNS：支持基于权重的路由
  • 服务健康检查：TCP / HTTP / MySQL 探测
  • 多数据中心：支持同城/异地多活
  • AP / CP 模式切换：根据场景选择一致性 or 可用性
