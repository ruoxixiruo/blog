1，Spring Boot 简介

Spring Boot 是 Spring 家族的核心子项目，旨在简化 Spring 应用的初始搭建和开发过程。通过”约定大于配置”的理念和自动配置机制，让开发者能快速创建独立、生产级的 Spring 应用。

为什么要用 Spring Boot？

  • 快速搭建：几分钟内创建一个独立运行的 Web 应用
  • 内嵌服务器：内置 Tomcat / Jetty / Undertow，无需部署 WAR 包
  • 自动配置：根据依赖自动配置 Spring 和第三方库
  • 起步依赖（Starter）：一站式引入相关依赖，无需手动管理版本
  • 生产就绪：内置健康检查、指标监控、外部化配置
  • 无代码生成：无需 XML 配置，几乎无需代码生成

与传统 SSM 对比：

对比项 SSM（Spring+SpringMVC+MyBatis） Spring Boot
项目搭建 配置繁琐，需要大量 XML 几分钟，自动配置
依赖管理 手动解决版本冲突 Starter 起步依赖自动管理
部署 打 WAR 包，部署到 Tomcat 打 JAR 包，内嵌服务器 java -jar
配置 大量 XML / properties application.yml，外部化配置
监控 需自行集成 Actuator 开箱即用

1，Vim 简介

Vim（Vi IMproved）是 Vi 编辑器的增强版，由 Bram Moolenaar 于 1991 年发布。它是绝大多数 Linux/Unix 系统的默认终端编辑器，以模式化编辑、强大的键盘操作和高度可定制而著称。

核心特点：

  • 模式化编辑：不同模式下的按键有不同含义

  • 高度可扩展：丰富的插件生态
  • 跨平台：Linux/macOS/Windows 均可使用
  • 轻量快速：启动毫秒级，无需 GUI

1，Python 并发概述

Python 有多种并发模型，选择取决于任务类型：

模型 适用场景 切换开销 GIL 影响
threading 多线程 I/O 密集型（网络、文件） 低 严重（无法利用多核 CPU）
multiprocessing 多进程 CPU 密集型（计算、图像处理） 高 无（各进程有独立 GIL）
asyncio 协程 高并发 I/O（大量网络连接） 极低 无影响（单线程）
concurrent.futures 简化线程/进程池操作 低/高 同上

GIL（全局解释器锁）：CPython 的全局锁，同一时刻只有一个线程执行 Python 字节码。I/O 操作时 GIL 会释放。

绕过 GIL 的策略：multiprocessing、C 扩展中释放 GIL、使用其他 Python 实现（Jython 无 GIL）、Python 3.13+ 可选无 GIL 模式。

java并发学习

发表于 2024-06-10 分类于 java
1，并发基础概念

进程与线程

  • 进程：操作系统资源分配的最小单位，各进程拥有独立的内存空间
  • 线程：CPU 调度的最小单位，同一进程内的线程共享堆和方法区，各线程有独立的栈和程序计数器

并发 vs 并行

  • 并发（Concurrent）：多个线程交替执行，宏观同时、微观串行（单核）
  • 并行（Parallel）：多个线程真正同时执行（多核）

线程安全三要素

  • 原子性：操作不可分割，要么全部成功要么全部失败
  • 可见性：一个线程对共享变量的修改，其他线程能立即看到
  • 有序性：程序执行的顺序按照代码先后执行（禁止指令重排序）

发表于 2024-06-01 分类于 java
1，Java 简介

Java 是由 Sun Microsystems（后被 Oracle 收购）于 1995 年发布的面向对象编程语言。James Gosling 是 Java 之父。

核心特点：

  • 跨平台：一次编译，到处运行（Write Once, Run Anywhere）—— 编译为字节码，由各平台 JVM 解释执行
  • 面向对象：封装、继承、多态
  • 自动内存管理：垃圾回收（GC），无需手动释放内存
  • 强类型：编译时类型检查，减少运行时错误
  • 丰富的生态：Spring、MyBatis、Hadoop 等

三大版本：

  • Java SE（Standard Edition）：标准版，核心基础
  • Java EE（Enterprise Edition）：企业版，Web 开发
  • Java ME（Micro Edition）：微型版，嵌入式
